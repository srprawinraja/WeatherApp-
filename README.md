# Weather Forecast App (Frontend)

An Android application that displays current weather conditions, today’s forecast, a 3-day forecast, and two additional forecast days predicted by a machine-learning model running on the backend.  
The app also shows air-quality data and supports city-name search.

---

## ✨ Features
- **Current Weather & Today’s Forecast**: Real-time temperature, conditions, and air quality.
- **Extended Forecast**: 3-day forecast plus 2 extra days predicted by the backend’s ML model.
- **City Search**: Search any city by name; the app automatically fetches latitude and longitude.
- **Clean UI**: Built with Jetpack Compose for a modern, responsive interface.

---

## 🛠 Tech Stack
- **Language:** Kotlin  
- **Frameworks & Tools:** Android Studio, Jetpack Compose, MVVM Architecture  
- **Networking:** Retrofit for API calls to the backend
